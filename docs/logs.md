# 调试日志

## 2026-10-17：BMI088 加速度三轴全为 0

### 现象

- `acc_data.x/y/z` 始终为 `0`。
- 温度可以正常读取。
- 芯片 ID、初始化和数据读取错误标志均为 `false`。

### 排查过程

1. 检查 IMU 线程，确认线程没有因 `INIT_ERR` 提前退出。
2. 检查 `ACC_DATA_ERR`，确认 HAL SPI 读取调用没有报告失 败。
3. 在 `ReadAccData()` 中设置断点，查看六个原始数据字节，发现全部为 `0x00`，排除数据拼接和比例换算问题。
4. 检查初始化顺序，发现 BMI088 加速度计上电后需要先通过一次无效读取切换到 SPI 模式。
5. 在软复位前增加无效读取后，三轴数据仍为 0。
6. 对照 Bosch 官方驱动发现：软复位近似重新上电，复位后还需要再次进行无效 SPI 读取。
7. 在软复位完成后补充第二次无效读取，再写入 `ACC_PWR_CTRL` 等配置。
